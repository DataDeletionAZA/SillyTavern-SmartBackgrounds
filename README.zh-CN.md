# SillyTavern 智能背景

这是一个在 SillyTavern 本机运行的背景处理扩展，用来解决两种问题：

- 很好看但尺寸偏小的图片，可以使用 Real-ESRGAN 修复细节并放大。
- 像素过多、切换时很卡的超高清图片，可以生成适合屏幕的 4K 级轻量版本。

图片不会上传到外部网站。处理完成后可以对比原图和新图；确认使用新图后，原图仍会保留到“背景”面板关闭，并且每张图片都能单独撤回。

## 功能

- 按钮直接放在 SillyTavern 原有的“背景”面板中。
- 自动判断应该使用 AI 细节修复、超高清减负，还是高画质压缩。
- 内置 `RealESRGAN_x4plus_anime_6B` 模型，不需要安装 Ollama 或另开 AI 服务。
- 默认使用较保守的 40% 细节强度，减少细线、文字和相邻轮廓粘连；也可以用滑杆调整。
- 支持勾选多张图片后批量处理；每张图片可以单独设置细节强度，并逐张运行以控制内存占用。
- 优先使用 WebGPU 显卡加速，无法使用时自动改用 CPU。
- 分块处理、显示进度，并且可以中途取消。
- 最长边限制为 4096 像素，输出高画质 WebP。
- 修复前后并排对比，两张图都可以点击放大。
- 新图片可以改名，并自动处理 Windows 不支持的文件名字符。
- 每张待确认的新图都有自己的撤回按钮；关闭“背景”面板后才删除对应原图。
- 支持简体中文、繁体中文和英文。
- 手机和平板可以正常使用处理好的背景，但会禁止运行图片处理，避免浏览器因内存不足而关闭。

## 安装

在 SillyTavern 中：

1. 打开“扩展”。
2. 选择“安装扩展”。
3. 粘贴：

   `https://github.com/DataDeletionAZA/SillyTavern-SmartBackgrounds`

4. 安装完成后重新载入 SillyTavern。

## 单张处理

1. 打开“背景”面板。
2. 点击某张背景上的闪光魔杖；也可以先选择背景，再点击顶部的“智能优化”。
3. 如果是小图，可以调整“细节强度”。强度越低越接近原图，强度越高则让模型重画更多细节。
4. 点击“开始处理”。
5. 对比原图和修复后的图片，必要时点击图片放大查看并修改新图片名称。
6. 选择“使用修复后的图片”后，可以立刻继续处理其他图片，不需要关闭面板。
7. 如果某张效果不好，点击那张新图上的撤回按钮，只会恢复这一张原图。
8. 全部确认无误后关闭“背景”面板，旧图才会被删除。

## 批量处理

1. 打开“背景”面板，点击顶部的“批量优化”。
2. 勾选要处理的图片，并分别设置每张图片的细节强度。
3. 点击“开始批量处理”。扩展会逐张运行，避免同时占用过多内存。
4. 每张图片处理完成后都会显示修复前后对比；两张图都可以放大，也可以修改新图片名称。
5. 确认使用的新图会加入背景图库。关闭面板前，每张结果仍可单独撤回。

## 隐私与兼容性

- SillyTavern 1.18.0 或更高版本。
- 支持 macOS、Windows 和 Linux。
- 推荐使用新版 Chromium 浏览器，以便使用 WebGPU；其他现代浏览器可以使用较慢的 CPU 模式。
- 扩展约 41 MB，因为真实模型和本地运行组件已经包含在安装包中。
- 目前只处理静态图片背景，不处理 GIF、动态 WebP 或视频背景。

AI 修复只在生成新图时运行。以后切换背景时，SillyTavern 会直接读取生成好的 WebP，不会再次启动模型。
