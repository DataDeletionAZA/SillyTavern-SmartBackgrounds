# SillyTavern 智能背景

这是一个在 SillyTavern 本机运行的背景处理扩展，用来同时解决两种问题：

- 很好看但尺寸偏小的图片，可以使用轻量 ESRGAN 模型进行本地 AI 高清化。
- 像素过多、切换时很卡的超高清图片，可以生成一份适合屏幕的 4K 级轻量版本。

扩展不会覆盖原图。每次处理都会在背景图库中增加一张新的 WebP 优化版本。

## 功能

- 按钮直接放在 SillyTavern 原有的“背景”抽屉中。
- 自动判断应该使用 AI 高清化、超高清减负，还是高画质压缩。
- 内置 2 倍、3 倍、4 倍 ESRGAN Slim 模型，不把图片上传到外部 AI 网站。
- 优先使用 WebGL 显卡加速，无法使用时自动改用 CPU。
- 分块处理、显示进度，并且可以中途取消。
- 最长边限制为 4096 像素，输出高画质 WebP。
- 支持简体中文、繁体中文和英文。
- 原始背景始终保留。

## 安装

在 SillyTavern 中：

1. 打开“扩展”。
2. 选择“安装扩展”。
3. 粘贴：

   `https://github.com/DataDeletionAZA/SillyTavern-SmartBackgrounds`

4. 安装完成后重新载入 SillyTavern。

## 使用

1. 打开酒馆的“背景”抽屉。
2. 点击某张背景上的闪光魔杖按钮；也可以先选择背景，再点击顶部的“智能优化”。
3. 查看扩展给出的处理方案。
4. 点击“开始处理”。
5. 处理后的版本会加入背景图库并自动选中。

AI 高清化只在第一次生成优化版本时运行。以后切换背景时，酒馆会直接读取生成好的 WebP 图片。

## 隐私

图片内容只在当前打开 SillyTavern 的浏览器中处理。AI 模型已经包含在扩展里，因此扩展安装完成后可以离线处理。

## 兼容性

- SillyTavern 1.18.0 或更高版本。
- 建议使用支持 WebGL 的现代浏览器。
- 当前只处理静态图片背景，不处理 GIF、动态 WebP 或视频背景。
